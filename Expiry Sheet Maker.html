Expiry Sheet Maker

Expiry Sheet Maker

Add your files or a whole folder. Each file name is read for its unique number and expiry date, and the result becomes an Excel sheet. Files are not uploaded. Only the names are read.

You can also drop files or a folder onto this card.

How a name is read
JK-01-AN 9522 - 20 Aug 2027 (2).pdf

Unique number JK 01 AN 9522, expiry 20 Aug 2027. The (2) is kept as a note. A name with only the number is listed with no date.

These are example names. Add your own files to replace them.

    The Excel sheet holds every row, not only the filtered ones. Days left and Status are formulas, so they stay current each day you open the sheet. Dates written as 05/08/2027 are read as day first, 5 August 2027.
